# argo-demos

Demo environments and recording tooling for Argo Rollouts projects.

| Directory | Description |
|-----------|-------------|
| [`rollouts-plugin-metric-ai/`](rollouts-plugin-metric-ai/) | AI-powered progressive delivery on GKE: the metric-ai plugin plus Kubernetes agents analyze canaries, abort bad rollouts, and open a remediation PR and a `jules` issue. Includes `demo.sh`, Cloudflare DNS automation, and a Playwright recorder that produces the demo video. |

See each directory's README for prerequisites, secrets and usage.
